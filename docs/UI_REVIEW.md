# Open Agricola 视觉设计 Review

> 审查日期：2025-04-22
> 审查范围：https://titanxxh.github.io/open-agricola/ 全部子页面（登录 / 大厅 / 工坊 / 设置 / 游戏对局）
> 方法：Playwright 自动截图（桌面 1440/1920 + 移动 390×844）+ `client/App.css` 源码分析

---

## 总体印象

Design tokens 体系搭得不错（绿/暖米/木色 + 4/8/16 间距 + 圆角分级），登录、大厅、设置三页是合格的"SaaS 风格"卡片化界面；问题集中在：

- **气氛缺失**："农场感/桌游感"只在 BGA 牌面图里出现，平台壳完全是 Notion 风
- **桌面宽屏下游戏页大片留白**
- **工坊与游戏内信息密度失衡**

### Design Tokens（`client/App.css:19-49`）

```css
--color-primary       #3a5a2c   /* 绿（主 CTA / 标题） */
--color-accent        #d4a017   /* 金（几乎没用上） */
--color-bg-warm       #fdf6e3   /* 米 */
--color-border        #cdb996   /* 木色描边 */
--agricola-font       Dominican / CalibriB  /* 仅用于品牌字与登录标题 */
/* spacing: 4 / 8 / 16 / 24 */
/* radius:  8 / 12 / 16 / pill */
```

Token 体系很完整，但**真正用到的只有 3 个色 + 1 个圆角**——金色 `--color-accent` 几乎没被任何页面消费，导致整个站没有"高光"，整体偏低对比、偏单调。

## 1. 登录页 `/?page=login`

### ✅ 好的地方

- 暖色渐变背景 + 白色卡片 + 顶部 4px 主色色条（`.login-card { border-top: 4px solid var(--color-primary) }`）是干净的入门体验。
- 卡片有 `fadeSlideIn` 入场动画（5334 行），细节加分。

### ⚠️ 问题

1. **品牌区构图割裂**：`brand-mark-centered` 容器居中，但里面 `.login-title` 是 `text-align: left`（3366 行），结果"图标 + Open Agricola"挤在卡片中段偏左，下面的 "登录以继续" 又居中——三段不在同一对齐轴上。
2. **语言切换器孤岛**：`.login-top-bar` 只有一个 `<select>` 浮在卡片右上角，且 `<select>` 是浏览器默认外观（米黄背景 + 默认箭头），与卡片其余 input 的圆角描边风格完全不一致。
3. **注册入口太弱**："没有账户？注册"用了下划线超链接体；对于新用户首次访问，应该是与登录同等权重的次要按钮（`.btn-secondary` 的米色款），降低试用心智成本。
4. 输入框 placeholder（"2-30 字符"、"至少 4 个字符"）直接当输入提示用，输入后这条规则就消失了——应该作为 `.form-hint` 文本常驻在 label 旁。

### 🔧 建议

- 整个品牌块统一居中（`text-align:center`），并把 logo 放大到 64px、与标题加 12px 间距。
- 用自绘 `<button>`-based 语言切换替换 `<select>`，复用 `.btn-small` 风格。
- "登录 / 注册"做成顶部 segmented control（两个 tab），代替底部隐藏的 mode 切换。
- 增加一个低调的"游客试玩"链接，对应 `?player=p1` 路径。

## 2. 大厅 `/?page=lobby`

### ✅ 好的地方

- 顶栏 brand → 语言/账号/登出，信息流畅。
- 三块卡片 `.lobby-section` 有 hover 上浮（`translateY(-2px)`），交互感不错。

### ⚠️ 问题

1. **三卡片高度严重不平衡**：`grid-template-columns: repeat(3, 1fr)` + 自动高度，"工坊"卡片只有一个按钮、几乎全空白；"开始游戏"两个按钮顶满。视觉上像被强行拉齐了边框却没填充。
2. **CTA 层级混乱**：三张卡里有 4 个按钮，其中 3 个用主色绿（创建多人/加入/进入工坊？等等"进入工坊"是 secondary 米色）——观察下来真正"应该首选"的"创建多人游戏"和次要的"单人模式"颜色对比拉开了，但右侧"加入"按钮也是主色绿，跟"创建多人"在视觉上同权重，新用户不知道该走哪条路径。
3. **"当前活跃房间" 占了半屏空高**：空状态只有一句"暂无活跃房间"居中灰字，下面是 600px+ 高的空白卡片+空白页面。**这是整页最浪费的区域**。
4. **品牌区在移动端断行**：390 宽截图里 "Open / Agricola" 被强制换行（图标 + 字 + 语言 + 用户名 + 登出 全挤在一行 max-width），结果 logo 偏移、字号瞬时压缩到 17px 左右。
5. 顶部"中文"select 和登录页一样是默认外观——风格断层。

### 🔧 建议

- 让"开始游戏"占两列、"加入/工坊"各占一列；或者改成 hero 横幅"创建多人游戏"+ 下面一行三个等高卡片（单人 / 加入 / 工坊）。
- 把 "当前活跃房间" 在空状态时改为单行折叠或一段引导文案 + 图示（"还没有人开局，邀请朋友试试看吧"+ 复制邀请链接按钮）。
- 顶栏在 < 640px 时改成 `flex-wrap` 第二行放语言/账号；logo 字保持单行不被挤。
- 用 segmented 风格统一 4 个 lobby CTA 的视觉权重（主色实心 / 主色描边 / 米色实心 三档差异化）。

## 3. 卡牌工坊（首页）`/?page=workshop`

### ✅ 好的地方

- 顶部 sandbox 卡片用了暖渐变（区别于其他白卡），明确"测试区"语义。
- "我的卡牌 / 精选 / 浏览" 三段式的信息架构合理。
- "精选" 用 ★ 字符 + 主色，是页面里唯一明显的彩色"高光"，方向对。

### ⚠️ 问题

1. **段落间分隔过弱**：4 段全是同样的 `.ws-section`（白卡 + 14px 圆角 + 极淡阴影）首尾一致，缺少 section 之间的呼吸/分组感。在页面长滚动场景下，section 标题（深绿、20px、bold）与正文混在一起，像 Markdown 文档而不是产品 UI。
2. **空状态没有"邀请下一步操作"**："你还没有创建卡牌""暂无精选卡牌""暂无已发布的卡牌" 三段文本几乎一样，且都没配 illustration / 引导按钮。第一次进入工坊的用户面对 4 段空白会迷茫。"我的卡牌"区里其实已经有一个右上角"+ 创建/修改卡牌"按钮——把它复制到空态居中位置，转化率会显著提高。
3. **"最新 / 最热" 切换 Tab 配色突兀**：用了深棕红 `#8b3a26` 风的填色 + 白字，与全站绿+米的体系完全脱节。
4. **沙盒卡片信息密度低**："当前还没有加入任何测试卡牌。当前配置：2 人局，默认牌组 A,B,C,D,E"——纯文字、无 CTA、无快捷修改入口，作为"沙盒入口"的功能感太弱。
5. **顶栏没用 `--app-edge-padding`**：工坊正文左右只有 ~24px 边距，但顶部"← 大厅 / 卡牌工坊"标题区几乎贴边——两套对齐线。

### 🔧 建议

- 给每个 section 加一行 12px 高度的分隔标识（细线 + `--color-border-light` 背景，或加个 icon 前缀）。
- 空态全部换成"图示 + 文案 + 主 CTA"的标准 EmptyState 组件，复用一次。
- 统一"最新/最热" segmented 用 `.btn-secondary` 米色款，活动态用主色绿。
- 沙盒卡放上 "2 人 ｜ 牌组 A B C D E" 的徽章式信息，加一个右侧 "进入沙盒" / "调整配置" 按钮。

## 4. 卡牌工坊 → AI 卡牌设计师

点击"创建/修改卡牌"后展开的面板。

### ⚠️ 问题（这页问题最多）

1. **左右两栏的"AI 提供商配置"完全重复**：左边卡牌图片配 Gemini/OpenRouter + 模型 + key；右边卡牌能力配 Gemini/OpenRouter + 模型 + key。**视觉上 80% 元素是镜像的**，造成信息噪音 ×2，用户也会困惑"为什么图片和能力要分别配 key？"。如果功能上确实可分（一个生成图、一个生成代码），UI 也应该折叠成一个共享的 "AI 配置" 面板 + 两个 "用此 provider 生成图 / 生成能力" 按钮。
2. **"✗ 图片 / ✗ 代码" 二级 tab 的 ✗ 字符严重误导**：✗ 在所有 UI 语境里都是 "关闭/删除/失败"，这里它实际是普通分隔图标。第一眼会以为这两个 tab 都被禁用了。
3. **顶部工具条信息过载**：8 个独立元素并排（小发展 tab / 职业 tab / 卡牌名输入 / ID 显示 / 保存到我的卡牌 / 加入沙盒并测试 / 本地化 / 关闭），全部同等权重，没有分组。建议：左侧分类 tab 一组、中间命名一组、右侧 action 一组并用 `gap` 拉开。
4. **底部固定栏文字过长**："已开启开发者模式 — 使用 Save/Load State 保存恢复进度，Draw Card 输入卡牌 ID 摸牌测试打出流程，Play Card 直接打出卡牌测试效果"——单行无换行规则，在窄屏直接溢出；并且这条 hint 文本与左侧"开始沙盒"按钮（绿色 pill）放在一起会喧宾夺主。
5. 输入区"前置条件 / 消耗资源"灰色 placeholder 没有 label，用户填了之后就不知道是哪一栏。

### 🔧 建议

- 将两个 AI 配置合并为一个 "AI 模型配置"折叠区放在顶部，左右两栏各只保留 "用 AI 生成"按钮。
- ✗ 替换为正确的 hide/show 图标（或干脆做成 chip-style toggle）。
- 顶部工具栏分组并用细分隔线（`border-left: 1px solid var(--color-border-light)`）。
- 给 input 都加上 visible label。

## 5. 账户设置 `/?page=settings`

### ✅ 好的地方

- 三段式信息组织清晰：基本信息 / 修改密码 / 其他。
- "← 返回大厅" 在左上角，一致的次级导航规范。

### ⚠️ 问题

1. **"登出所有设备（清除 session）" 应是 destructive 但被画成了普通 secondary 按钮**（米色 + 木色描边）。`.btn-danger` 已经在样式里定义好了（5159 行 `--color-danger #d74a3a`）但这里没用——语义和样式不一致。
2. **保存按钮是全宽主色绿**：登录页用全宽主色按钮是合理的，因为只有一个目标动作；但设置页里 "保存"、"修改密码"、"登出所有设备" 三个按钮都做成全宽块，整页变成 "三块横条" 的节奏，视觉上像未分类的 to-do list。
3. **"显示名称" 的 input 与 "保存" 之间几乎贴在一起**（`gap: 16px` 但视觉上太近），导致点击 "保存" 时容易误以为还在表单里。
4. 用户名显示 "用户名：xxh（不可修改）" 用了同样字号灰字，没有 lock 图标——视觉上像"未填写"。
5. 顶部又出现了那个默认外观的语言 select。

### 🔧 建议

- "登出所有设备" 切到 `.btn-danger`（红底白字），并把 "其他" 区改名为 "危险操作"，用红色细边框框起来。
- "保存"、"修改密码" 改为局部宽度（200px 左右），右对齐放在表单底部。
- 用户名行加 🔒 icon，灰字配淡米色背景的 readonly chip。

## 6. 游戏对局页（单人模式，1920×1080）

**视觉问题最严重的一页。**

### ⚠️ 问题

1. **桌面宽屏严重浪费**：`.game-layout` 用 `grid-template-columns: minmax(0, 1fr) minmax(280px, 360px)`（606-610 行），主区 + 右侧 log 列。但主区里又是"行动板（图）+ 玩家区"两栏布局，行动板宽度被 BGA 资源固定（830px），结果在 1920×1080 下：
   - 整个内容大约只用了中间 1280px
   - 左右各 ~320px 的绿草地 `background.jpg` 平铺
   - 行动记录右栏 380px 几乎是空白卡片（只显示 "信息列表（第 1 轮）"）

2. **绿草地 `background.jpg` 平铺过于刺眼**：高饱和、高频草纹理填满空白，让所有白色面板都像"飘在草地上的卡片"，没有桌面/木板/羊皮纸的承载感。BGA 原版用的是木桌底+羊皮纸面板，这里失去了这个层次。

3. **回合阶段卡（顶部 3 张棕底白圆）过小**：在巨大空白中显得像 placeholder。Agricola 的"阶段+收获"是核心节奏指示，应该被放大且保留 stage 编号 / 即将到来的事件预告。

4. **底部浮动控制条**（左下三个 pill：上一步 / 离开房间 / 开发者）颜色与背景对比弱（米白 pill 浮在草地上），且离功能区很远——放在 `.interaction-bar`（fixed bottom 全宽）里会更顺。

5. **玩家手牌区长度失控**：`fullPage` 截图显示职业卡 + 小发展卡各 7 行单列堆叠（约 12 张卡 × 100px 高 = 1200px），远超主区行动板高度（约 600px），导致页面要滚动到不必要的深度。在桌游场景里手牌应该被设计成 "可折叠列表" 或 "悬浮卡组"。

6. **信息架构主次弱**：标题 "行动区 / 玩家农场 / 行动记录" 三个 16px 黑字平排，但实际"我现在该做什么"的信息（pending action / 我的回合提示）没有视觉峰值。

### 🔧 建议（按优先级）

- **P0**：在 `min-width: 1600px` 媒体查询里给行动记录列固定到 320px，剩余空间分配给一个"全屏视角"——可以放第二个玩家的农场，或者放 mini map / 计分板。
- **P0**：把背景从 `background.jpg` 平铺换成 `木桌纹理 + 中央羊皮纸主面板`（参考 BGA 实物贴图），即使重用 `background.jpg` 也加 `linear-gradient(rgba(0,0,0,0.15), rgba(0,0,0,0.4))` 暗化，让前景白卡片浮起来。
- **P1**：手牌区改成横向 carousel（单行 + 左右滚动），点击卡牌再展开详情。
- **P1**：阶段卡放大、加阶段倒计时和"将触发"标识。
- **P2**：右侧行动日志加图标分类（🌾 收获 / 🐑 动物 / 🏠 建造），不要纯文字。

## 7. 移动端

### ⚠️ 问题

1. 大厅顶栏"Open Agricola" 强制换行 + 图标错位。
2. 工坊顶部 `<select>` 占满全宽，看起来像 "← 大厅 / 卡牌工坊" 标题的下属表单——其实是语言切换。
3. "搜索" 输入框 + "搜索/最新/最热" 按钮三段排版没换行，按钮被压缩到 56px 宽，"最新/最热"两个 chip 是棕红色与全站绿米色调突兀。
4. 没看到底部 tab bar / 全局导航——移动端用户在工坊页只能靠 "← 大厅" 单点回退。

### 🔧 建议

- 移动端固定底部 tab bar：大厅 / 工坊 / 设置 三入口（可以参考 BGA mobile）。
- 顶部 `<select>` 替换为带语言图标的图标按钮，弹出选单。

## 三个最值得先做的改动

### 1. 统一 `<select>` 与 destructive button 的样式

写一个 `<SelectButton />` 组件；让 `.btn-danger` 真正应用到危险操作上。改完整站观感会立刻"成体系"。

### 2. 做一套桌游气氛 token

`--bg-wood`, `--bg-parchment`, `--shadow-paper`，把游戏页主背景从草地平铺换成"木桌底 + 中央羊皮纸"，让 BGA 卡牌资源不再"漂浮"在 SaaS 卡片上。

### 3. 重构游戏对局页的宽屏布局

把右侧空荡荡的"行动记录"列让位给"对手农场 / 计分板 / 阶段时间轴" —— 这是用户停留时间最长的页，每改进 10% 都比改大厅有价值。
