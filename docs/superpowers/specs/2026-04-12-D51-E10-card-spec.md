# D51_Archway & E10_StrawHat Card Spec

## D51_Archway

**类型:** PlayerActionCard（打出后创建行动位）

**费用:** 2 Clay | **VP:** 4 | **前提:** 无职业卡

**效果:**
1. **行动位（所有玩家可用）：** 放置工人 → 获得 1 食物
2. **onBeforeReturnHome：** D51 上有工人的玩家可以将该工人移动到一个**未被占用**的行动格并执行该行动（optional）

**BGA 规则细节（来自 rulings）：**
- 不能移动到已占用的行动格，即使有其他卡允许使用已占用格
- 例外：如果打出了 A28_ForestSchool，可以移动到已占用的 Lessons 行动格
- D51 行动位属于"所有人可用"类型，非仅限卡主
- 如果多个工人在 D51 上（如通过 B151_LittlePeasant），每个工人分别获得移动机会

**关键行为：**
- `onBuy`: 将 D51 行动位注入 `state.actionSpaces`
- `onBeforeReturnHome`: 检查 `d51Space.takenBy === player.id`，不是检查卡牌所有权
- `move-farmer-to-space` action: 列出可用未占用格（排除 D51 自身），玩家选择后执行目标格 action，标记 `takenBy`，不操作 `workersAvailable`

**当前已实现模块：**
- `shared/cards/player-action-space.ts` — PlayerActionCard 行动位注册表
- `shared/actions/effects/move-farmer-to-space.ts` — 通用"移动工人到未占用格"action
- `shared/cards/D/D51_Archway.ts` — registerPlayerActionSpace + registerCardEffect

## E10_StrawHat

**类型:** MinorImprovement（不创建行动位）

**费用:** 1 Reed

**效果:**
- **onBeforeReturnHome（仅第 3、6 轮）：** 如果玩家有工人在 Farmland（`farmland`）行动格上，可以选择：
  - A) 将该工人移动到未被占用的行动格并执行（使用 `move-farmer-to-space` action，排除 `farmland`）
  - B) 获得 1 食物
  - 或 decline（不执行任何操作）

**关键行为：**
- 仅在第 3 和第 6 轮触发
- 检查 `farmlandSpace.takenBy === player.id`
- 如果没有可用的未占用格，只提供"获得 1 食物"选项
- xor optional 流：[move-farmer-to-space, gain 1 food]

**当前已实现模块：**
- `shared/cards/E/E10_StrawHat.ts` — registerCardEffect with onBeforeReturnHome

## 共用基础设施

### player-action-space.ts
- `registerPlayerActionSpace(config)`: 注册 PlayerActionCard 的行动位配置
- `createPlayerActionSpaces(state)`: 扫描所有玩家 `minorPlayed`，为已注册的 PlayerActionCard 创建 ActionSpace
- `normalizeState` / `rehydrateState` 调用此函数追加动态行动位

### move-farmer-to-space action
- `execute`: 列出可用未占用格（排除 `params.excludeSpaceId`），A28_ForestSchool 例外允许已占用 Lessons
- `resolveChoice`: 标记目标格 `takenBy`，执行目标格 action，不减 `workersAvailable`

## 测试覆盖要求

### D51_Archway 测试用例

1. **PlayerActionSpace 注册**: `getPlayerActionSpaceConfig('D51_Archway')` 应返回配置，access='all'
2. **createPlayerActionSpaces**: 当玩家 minorPlayed 包含 D51 时，创建对应 ActionSpace
3. **createPlayerActionSpaces 不重复**: 同一卡不会创建两个 ActionSpace
4. **D51 行动位 execute**: 执行后玩家获得 1 食物
5. **onBuy**: 调用后 `state.actionSpaces` 包含 D51 行动位
6. **onBeforeReturnHome 触发**: D51 行动位 `takenBy === player.id` 时返回 move-farmer-to-space flow
7. **onBeforeReturnHome 不触发（非该玩家）**: D51 的 takenBy 是其他玩家时不触发
8. **onBeforeReturnHome 不触发（无人使用）**: D51 的 takenBy 为 null 时不触发
9. **onBeforeReturnHome 不触发（无可用行动格）**: 所有行动格都被占用时不触发

### E10_StrawHat 测试用例

1. **第 3 轮触发**: round=3, 工人在 farmland → 返回 xor flow
2. **第 6 轮触发**: round=6, 工人在 farmland → 返回 xor flow
3. **非 3/6 轮不触发**: round=4, 工人在 farmland → undefined
4. **工人不在 farmland 不触发**: round=3, farmland.takenBy 是其他玩家 → undefined
5. **farmland 无人不触发**: round=3, farmland.takenBy=null → undefined
6. **无可用行动格时只有食物选项**: round=3, 所有格占满 → xor 只有 gain food 一个 child
7. **有可用格时两个选项**: xor 有 move-farmer-to-space + gain food 两个 child
8. **卡未打出不触发**: minorPlayed 不含 E10 → undefined

### move-farmer-to-space 测试用例

1. **execute 列出未占用格**: 排除 excludeSpaceId 和已占用格
2. **execute 无可用格时 fail**: 所有格占满 → type='fail'
3. **A28_ForestSchool 例外**: 有 A28 时，已占用 Lessons 格出现在选项中
4. **resolveChoice 执行目标格**: 标记 takenBy，调用 space.execute
5. **resolveChoice 无效 choice**: 不存在的 space id → fail
