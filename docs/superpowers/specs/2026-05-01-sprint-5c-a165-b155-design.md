## 2. A165 PigBreeder 实现

### 2.1 BGA 源（`bga-agricola/modules/php/Cards/A/A165_PigBreeder.php`）

```php
public function onBuy($player) {
  return $this->gainNode([PIG => 1]);

public function isListeningTo($event) {
  return $this->isPlayerEvent($event) && $event['type'] == 'EndOfRound' && Globals::getTurn() == 12;
}

public function onPlayerEndOfRound($player, $event) {
  if ($player->breedTypes()[PIG]) {
    return [
      'action' => SPECIAL_EFFECT,
      'args' => ['cardId' => $this->id, 'method' => 'breedAnimal', 'args' => [PIG]],
    ];
  }
}

public function breedAnimal($type) {
  $player = $this->getPlayer();
  if (!$player->breed($type, 'card')) return;
  Engine::insertAsChild([
    'action' => REORGANIZE,
    'pId' => $player->getId(),
    'args' => ['trigger' => HARVEST, 'breedTypes' => [$type => true]],
  ]);
}
```

`player->breed($type, 'card')` 是 BGA 通用 breed 入口：检查 capacity + ≥2 → +1 → 触发 BreedAnimal 事件链。

## 3. B155 ArtTeacher 实现

### 3.1 BGA 源（`bga-agricola/modules/php/Cards/B/B155_ArtTeacher.php`）

```php
public function onBuy($player) {
  return $this->gainNode([WOOD => 1, REED => 1]);
}

public function onPlayerComputeCostsOccupation($player, &$args) {
  foreach ($args['costs']['trades'] as $trade) {
    if (isset($trade[FOOD])) {
      $food = $trade[FOOD];
      for ($i = 1; $i <= $food; $i++) {
        $trade[FOOD] -= $i;
        if ($trade[FOOD] <= 0) unset($trade[FOOD]);
        $trade[FOOD_TRAVEL] = $i;
        $trade['sources'][] = $this->id;
        $args['costs']['trades'][] = $trade;
      }
    }
  }
}
```

含义：玩家付 occupation cost 时，每个含 FOOD 的 cost-trade 都派生备选（用 i 个 traveling-players food 抵 i 个 food cost）；玩家在 selectPayment 选用与否。

```ts
// shared/actions/helpers/payment.ts (applyPaymentSolution 内部，trades 应用循环)
solution.tradesUsed.forEach(({ trade, times }) => {
  if (times <= 0) return
  // 既有 from / to apply 逻辑保持
  // ...
  if (trade.sideEffect) {
    applyTradeSideEffect(state, trade.sideEffect, times)
  }

// 数据驱动 dispatcher，未来加 effect type 只需加 case
const applyTradeSideEffect = (
  state: GameState,
  eff: TradeSideEffect,
  times: number,
): void => {
  switch (eff.type) {
    case 'drainSpace': {
      const space = state.actionSpaces.find((s) => s.id === eff.spaceId)
      if (!space?.resources) return
      const cur = space.resources[eff.resource] ?? 0
      space.resources[eff.resource] = Math.max(0, cur - times)
      return
    }
  }
}
```

### 3.4 与 BGA 的语义对齐

| 场景 | BGA | 我方等价 |
|---|---|---|
| 玩家不想用 TP food | trade 是备选项，selectPayment 选其他 trade | trade.max=tpFood，玩家选 0 次使用 |
| TP 5 food，cost 2 food | 派生 i=1, 2 共 2 个 trade；玩家选 i=2 | 单 trade max=5，玩家用 2 次 |
| TP 1 food，cost 2 food | 派生 i=1 trade；玩家用后还要付 1 food | 单 trade max=1；玩家用 1 次 + 自付 1 food |
| 多张 occupation 连续付费 | 每次 hook 重新派生 | computeCosts listener 每次重跑 max 重算 |
| anytime occupation 入口（D9 等） | hook 触发条件是 cost 计算，与入口无关 | actions:['play-occupation'] 覆盖所有 occupation 入口 |

## 4. Breed unified effect + onBreed listener phase

### 4.1 新文件 `shared/actions/effects/breed.ts`

```ts
import type {
  ActionDefinition, ActionExecutionResult, ActionFlow,
  GameState, HarvestBreedSummary, PlayerState,
} from '../../game/types'
import { getAssignedAnimalCount, getTotalAnimalCapacity } from '../helpers/animal-zones'
import { fireOnBreedListeners } from '../../cards/card-listeners'

type AnimalType = 'sheep' | 'boar' | 'cattle'

type BreedOptions = {
  animalTypes?: ReadonlyArray<AnimalType>
  sourceCard: string
}

export const breed = (
  state: GameState,
  player: PlayerState,
  opts: BreedOptions,
): { breedSummary: HarvestBreedSummary } => {
  const types = opts.animalTypes ?? (['sheep', 'boar', 'cattle'] as const)
  const summary: HarvestBreedSummary = { resources: {}, animalTypes: 0, animalCount: 0 }
  for (const type of types) {
    const free = getTotalAnimalCapacity(player) - getAssignedAnimalCount(player)
    if (free <= 0) break
    if (player.resources[type] < 2) continue
    player.resources[type] += 1
    fireOnBreedListeners(state, player, { animalType: type, count: 1, sourceCard: opts.sourceCard })
    summary.resources[type] = 1
    summary.animalTypes += 1
    summary.animalCount += 1
  }
  return { breedSummary: summary }
}

export const breedAction: ActionDefinition = {
  id: 'breed',
  // execute reads ctx.args = { animalTypes?, sourceCard }
  execute: (state, player, ctx): ActionExecutionResult => {
    const { breedSummary } = breed(state, player, {
      animalTypes: ctx.args.animalTypes,
      sourceCard: ctx.args.sourceCard,
    })
    if (ctx.args.sourceCard === 'harvest') {
      state.harvestBreedSummary ??= {}
      state.harvestBreedSummary[player.id] = breedSummary
      // log line: harvestBreedDetail (复用现有 i18n key)
    }
    if (breedSummary.animalCount > 0) {
      return { type: 'animalReorg', sourceId: `card:${ctx.args.sourceCard}` }
    }
    return { type: 'ok' }
  },
}

export const breedLeaf = (sourceCard: string, animalTypes?: AnimalType[]): ActionFlow => ({
  type: 'leaf',
  effect: { type: 'breed', sourceCard, animalTypes },
  sourceCard,
})
```

### 4.2 onBreed listener phase

```ts
// shared/cards/card-listeners.ts
export type CardListenerPhase =
  | 'before' | 'during' | 'after' | 'immediatelyAfter'
  | 'computeCosts' | 'computeArgs' | 'computeReplace' | 'isDoable'
  | 'onBreed'                                                 // ← 新增

export type BreedListenerContext = CardListenerContext & {
  breed: {
    animalType: 'sheep' | 'boar' | 'cattle'
    count: number
    sourceCard: string
  }
}

// 触发器 — 由 breed effect 内部调用，复用既有 getMatchingListeners + executeCardListener
export const fireOnBreedListeners = (
  state: GameState,
  player: PlayerState,
  payload: { animalType: AnimalType; count: number; sourceCard: string },
): void => {
  const baseCtx: CardListenerContext = buildBaseCtx(state, player, {
    phaseFilter: 'onBreed',
    breed: payload,
  })
  for (const matched of getMatchingListeners(baseCtx)) {
    if (!matched.registration.phases?.includes('onBreed')) continue
    executeCardListener(matched.registration, baseCtx, { ownerPlayerId: matched.ownerPlayerId })
  }
}
```

注：`fireOnBreedListeners` 是同步触发（每 +1 立即 fire），与 BGA 事件链顺序一致。listener handler 可写卡内 cardStates、log、产 ActionFlow（如果设计需要）。本 sprint 不强求 listener 能产 flow（避免 leaf 内嵌 flow 的复杂度）；listener handler 主要 mutate cardStates / log。

### 4.3 Harvest 路径迁移

**删除**：

- `shared/actions/helpers/breed-animals.ts` 整文件
- `game-core.ts applyBreedPhase`（line 2517-2526）
- `game-core.ts continueAfterFeedingPhase` 内 line 2505-2511 的 ad-hoc `hasPendingAnimals` 检查

**改造 `continueAfterFeedingPhase`**：

```ts
private continueAfterFeedingPhase(playerIndex = 0, cardIndex = 0): SessionResponse {
  if (this.continueStageHook('onEndHarvestFeedingPhase', playerIndex, cardIndex)) {
    return this.respond()
  }
  const harvestOrder = this.getHarvestPlayerIndices()
  harvestOrder.forEach((index) => {
    const player = this.state.players[index]
    if (player) runAfterFeedHooks(this.state, player)
  })
  this.state.log.unshift({ key: 'log.harvestPhaseBreed' })
  this.state.harvestBreedSummary = {}

  // 构造跨玩家 breed flow
  const flow = buildHarvestBreedFlow(harvestOrder, this.state.players)
  return this.startStageFlow(flow, 'onBreedPhase', 0, 0)
}

// 帮助函数
const buildHarvestBreedFlow = (
  order: number[], players: PlayerState[],
): ActionFlow => ({
  type: 'sequence',
  children: order.flatMap((idx) => {
    const p = players[idx]
    if (!p) return []
    return [
      { type: 'playerSwitch', playerId: p.id },
      breedLeaf('harvest'),  // sourceCard='harvest'
    ]
  }),
})
```

`startStageFlow(flow, 'onBreedPhase', ...)`：`'onBreedPhase'` 加进 `StageResumeState['hook']` 联合类型，作为 resume token。该 stage 不接 card listener（不调 `runCardEffectHook`），engine 跑完整个 flow 后 game-core 回 `continueEndHarvestEffects`。leaf return `{ type: 'animalReorg', ... }` 时 game-core line 2080 已有逻辑自动设置 pending；玩家完成 reorg 后 engine 继续下一个 leaf。

`shared/logic/round.ts performHarvest` 不再做 breed（删 `breedAnimals(player)` 调用）。harvest summary 的 breed 部分由 `game-core` 走 leaf 累计到 `state.harvestBreedSummary`，与现有 reap / feed 部分一致。
