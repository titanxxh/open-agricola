# 社区扩展卡（Community Deck）

这些卡由工坊用户通过 LLM 设计、提交 PR 合入主仓库。maintainer review 后入库。质量 / 平衡性可能和官方 A-E deck 有差异。

房间创建时勾选"启用社区扩展卡（community deck）"才会进入发牌池；默认关闭。
